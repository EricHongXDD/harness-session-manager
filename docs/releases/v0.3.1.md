# Harness Session Manager v0.3.1

Windows 本地工作区、对话与备份管理工具，原项目名称为 DSH Space。

- 按 Harness 工作区分组显示对话，保留完整文件夹路径、备注、归档和子对话。
- 阅读会话中的图片，手动 ZIP 备份包含引用的图片，可选择备份导入并恢复。
- 隐藏和恢复直接执行，不创建自动 ZIP；恢复后清理隐藏副本及记录。
- 支持对话、隐藏组和工作区永久删除，删除前确认实际范围；共享图片、项目代码和手动 ZIP 保留。
- 操作失败时弹窗显示完整错误，包括退出 Harness 的提示。
- 提供 Windows 自动测试、生产程序合成验收、打包和标签发布流程。

## 下载与升级

下载 `HarnessSessionManager-0.3.1-windows-amd64.zip` 后解压运行，或下载单独的 EXE。`SHA256SUMS.txt` 提供校验值。需要 Microsoft WebView2 Runtime。

升级前关闭旧程序。本地数据继续使用 `%LOCALAPPDATA%\DSHSpace`，兼容已有隐藏记录和备份。执行备份、隐藏、恢复或永久删除前，请退出 Harness 的托盘、网页服务和命令行。

当前适配 Harness 0.2.0-rc.2 的 v4 会话；数据保存在本机。通过 Go／前端自动化和生产 EXE 合成验收，尚未完成真实桌面人工交互验收。
